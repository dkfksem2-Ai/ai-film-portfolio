# AI 영상 포트폴리오 V9.12

압축을 풀면 나오는 index.html, picnic.html, room.html, CSS/JS 파일과 assets 폴더를 GitHub 저장소의 배포 루트에 함께 올립니다. GitHub Pages에서는 해당 브랜치의 /(root)를 배포 경로로 지정합니다. 빌드 과정은 없습니다.

최종 상영 영상은 video-config.js의 기존 외부 영상 주소를 사용하므로 인터넷 연결이 필요합니다. Google Fonts와 Pretendard CDN 실패 시 시스템 글꼴로 표시됩니다.

소풍의 쪽지는 기본적으로 이 기기에 저장됩니다. notes-config.js의 공개키가 비어 있어 기기 간 저장소는 연결되지 않았습니다. secret/service_role 키를 프런트엔드에 넣지 마세요.

반찬통의 왕복은 락앤락 비공식 포트폴리오 작품이며, 틈GO는 가상 서비스입니다. 글꼴 라이선스는 assets/fonts/Galmuri-OFL.md에 보존했습니다.

V9.10에서는 첫 화면을 화면 높이에 맞췄습니다. 반찬통 무대는 햇살이 드는 부엌 선반의 유리 반찬통에서, 틈GO 무대는 원룸 세탁기 옆 수납장의 접힌 수건에서 장면이 시작됩니다. 모바일에서도 무대를 고정하고 시작 소품을 모두 표시합니다. 동작 줄이기 설정에서는 각 장면과 캡션을 세로로 읽을 수 있습니다.

음악과 볼륨은 조각 담기 체험을 펼쳤을 때만 보입니다. ‘체험 음악 켜기’로 직접 시작하며 볼륨 변경만으로 재생되지 않습니다. 체험을 닫거나 광고 영상을 재생하면 체험 음악을 멈춥니다. 광고 영상의 소리 크기는 영상 플레이어에서 조절합니다.

조각 담기는 제작 과정 다음, 소개 직전의 선택 체험입니다. 11개 조각을 용기에 담거나 키보드 Enter/Space로 선택하면 해당 작품의 영상·체험 링크가 열립니다. 소풍과 현우방은 별도 페이지이며 기존 동작을 유지합니다. 영상 모델이나 편집 해상도는 기존 작품 정보에서 확인된 표현을 사용했습니다.
