MOTION EDITORIAL / V5 — 1920 × 950 화면 규격 적용
========================================

선생님 지시: 한 화면 1920 × 950, 콘텐츠는 좌우 1280~1440 안.

V5에서 바뀐 것
- 콘텐츠 폭: 1920 화면에서 가운데 1440(좌우 240씩 여백). 1440보다 좁은 화면에서는 여백을 유지한 채 줄어듭니다.
- 핵심 글 블록(PROCESS 목록 등)은 안쪽 1280 안에 둡니다.
- 헤더·푸터: 배경은 화면 끝까지, 로고·메뉴·버튼은 1440 안으로 옮김(V4는 화면 끝 78px에 붙어 있었음).
- 히어로 장식(사진 2장, IN MOTION 도장, 세로 글씨)이 1440 밖으로 나가지 않게 위치 조정.
- 한 화면 단위: 헤더 85 + 화면 865 = 950. 페이지 전체가 9화면(총 7,870px)으로 딱 나뉩니다.
  1 히어로 / 2 작품 소개 / 3 반찬통 메인 / 4 반찬통 노트·시대별 장면 / 5 인터루드
  6 틈GO 메인 / 7 틈GO 노트·장면 / 8 제작 과정 / 9 소개 + 푸터
- 작품 메인 화면은 제목 + 대표 이미지가 한 화면 안에 들어오도록, 이미지 높이를 화면에 맞춰 자동 계산.
- 태블릿·모바일(1100px 이하)에서는 고정 높이를 풀고 자연스럽게 흐릅니다.

검수용 가이드
- 페이지에서 G 키를 누르면 1440(빨강 실선)·1280(파랑 점선) 가이드가 켜지고, 다시 누르면 꺼집니다.
- 주소 끝에 #guide 를 붙여 열면 가이드가 켜진 상태로 시작합니다.

검수 결과 (1920 × 950, Chromium)
- 1440 밖으로 나가는 요소 0개(배경 띠 제외), 각 화면 높이 865 확인.
- 1440 × 900, 1366 × 768, 390 × 844에서 가로 스크롤 없음.

- 작품 이미지 안의 ▶ 버튼은 약 5초 프리뷰입니다. 완료하면 원래 화면으로 돌아옵니다.
- VIEW FILM은 OTT 상세 모달, PRODUCTION NOTES는 제작·컷별 데이터 확인입니다.

5초 프리뷰 및 실제 영상 교체
- assets/previews/memory-teaser.mp4 / tumgo-teaser.mp4
- 두 파일은 기존 프로젝트 스틸에서 만든 '모션 스터디'로 완성 광고 영상이 아닙니다.
- 실제 영상의 5초 하이라이트가 있다면 동일한 파일명으로 교체하기만 하면 됩니다.
- 사이트의 영상 프리뷰는 음소거 상태로 시작합니다(브라우저 재생 정책 고려).

최종 전체 MP4 연결
- site.js 앞부분 publishedVideoSources를 수정:
  const publishedVideoSources={memory:'assets/films/memory-final.mp4',tumgo:'assets/films/tumgo-final.mp4'};
- ZIP에는 최종 마스터 영상이 포함되지 않습니다.
- 마스터와 기획서 타임코드가 다르면 전체 컷 동기화 검수가 필요합니다.

기술 적용
- AE F9 스타일의 Ease Out / Ease InOut 유사 cubic-bezier 속도 곡선
- 스크롤 진입/반전 없는 낮은 속도·긴 감속, requestAnimationFrame + damping 기반 패럴랙스
- 스크롤 구간을 기준으로 한 3장면 전환, 마우스 위치로 수동 탐색
- 5초 무음 Inline HTML5 Video, 재생 상태/진행 바/종료 자동 복귀
- 모션 줄이기 OS 접근성 설정(prefers-reduced-motion) 적용
- 외부 라이브러리, 외부 폰트, Tailwind CDN, 불필요한 3D 엔진 없음
